# ShapefileReader
ShapefilerReader implemented in Swift


Clone or copy the ShapefileReader.swift to your project and adjust paths and environment. See the example usage in example.swift for adding an icon to your UI. The default setting in the code is to add the icon on the top right. Feel free to adjust to your likings.


Requires all four .shp, .shx, .prj, and .dbf files as input and stored on the device. 


Please feel free to reach out and open issues if you have any. Thanks.
